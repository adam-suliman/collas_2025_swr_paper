# `meta_fast_memory`

`meta_fast_memory` — это новый вариант RMT для ViT на incremental-CIFAR, добавленный в `vit_experiment.py`. Он сохраняет ту же архитектуру `MemoryVisionTransformer` и тот же механизм memory tokens, но меняет способ обучения памяти внутри каждого минибатча.

## Как работает стандартный `fast_memory`

1. Использует текущий батч для вычисления внутренней функции потерь памяти.
2. Делает один шаг градиентного обновления памяти.
3. Затем вычисляет внешнюю функцию потерь модели на том же самом батче, но уже с адаптированной памятью.
4. Обновляет веса модели по этой внешней функции потерь.

Вкратце, `fast_memory` - это:

> «Адаптация памяти таким образом, чтобы она помогала на текущем батче».

## Как работает `meta_fast_memory`

`meta_fast_memory` заменяет эту схему на режим `support/query`:

1. Делит каждый минибатч на подмножества `support` и `query`.
2. Записывает память, используя только подмножество `support`.
3. Оценивает адаптированную память и на `support`, и на `query`.
4. Оптимизирует веса модели по гибридной внешней функции потерь, построенной из `post-write` потерь на `support` и `post-write` потерь на `query`.

Вкратце, `meta_fast_memory` — это:

> «Адаптация памяти на `support`, а затем обучение модели так, чтобы эта память была полезна на `query`».

## Основные практические отличия

- `fast_memory` использует один и тот же батч и для записи, и для чтения.
- `meta_fast_memory` использует разделение `support/query` внутри батча.
- `fast_memory` логирует диагностические метрики по `memory-loss`.
- `meta_fast_memory` логирует `support/query` meta-диагностику:

  - `rmt/meta_support_loss_per_minibatch`
  - `rmt/meta_query_loss_per_minibatch`
  - `rmt/meta_support_accuracy_per_minibatch`
  - `rmt/meta_query_accuracy_per_minibatch`
  - `rmt/meta_query_improvement_per_minibatch`

## Отличие в инициализации

Есть и различие в инициализации:

- `fast_memory` может опционально использовать обучаемый `memory prior`.
- `meta_fast_memory` принудительно использует обучаемый prior, потому что этот вариант предназначен для мета-обучения общего начального состояния памяти.
